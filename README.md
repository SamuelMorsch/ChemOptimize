# ChemOptimize v0.1

Agente Inteligente baseado em objetivos para otimização de envasamento industrial (*Bin Packing Problem*).

**Integrantes:** Samuel Morsch, João Vitor da Silva Bast e George Lucas Silva Brigido.

## Requisitos de Sistema
- Python 3.8 ou superior
- Bibliotecas: `matplotlib`

## Instruções de Instalação e Execução
1. Clone este repositório ou baixe a pasta do projeto.
2. Abra o terminal na raiz da pasta do projeto.
3. Instale a biblioteca gráfica executando o comando:
   `pip install matplotlib`
4. Execute o agente inteligente com o comando:
   `python main.py`

Ao rodar, o console exibirá o relatório de distribuição ideal dos frascos e abrirá uma janela com o gráfico de convergência da heurística *Simulated Annealing*.
